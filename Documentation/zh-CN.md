## 基本用法

海报展示组件提供了一系列自定义参数，用于调整展示效果，以适应不同的展示需求。目前，`Prefabs` 目录中提供了以下多种常用预制件变体。你可以在 `Examples` 目录中的场景中查看它们的示例。在将合适的预制件添加到场景中后，通常需要调整预制件上的 `PosterDisplayController` (Contoller) 组件的 `Endpoint` 参数来指定获取在线**海报资源**的 API 端点地址，以便组件能够正确获取和展示**海报内容**。

预制件的名称由一下几个部分组成：

```
PosterDisplay-<Amount>-[Strided]-<ShaderVariant>-[FeatureExt]
PosterDisplay-<数量>-[步长]-<着色器变体>-[特性扩展]
```

其中：

- `Amount`（数量）部分用于指定预制件展示的**海报栏位**数量
  - `Solo` (单个) 表示预制件在*单个***展示栏位**中展示一组**海报资源**
  - `Multi` (多个) 表示预制件在*多个***展示栏位**中展示一组**海报资源**
- `Strided` (步长) 部分用于指定 `Multi` 类型预制件是否调整了 `Stride` 参数来控制多栏位展示的内容错开
  - `Strided` 表示预制件调整了 `Stride` 参数来控制多栏位展示的内容错开，每个**展示栏位**将负责展示一组**海报资源**中的不同内容
   - 如果没有该部分则表示预制件没有调整 `Stride` 参数，多个**展示栏位**将依次展示**海报资源**中的内容
- `ShaderVariant` (着色器变体) 部分用于指定预制件使用的**海报材质**类型
  - `Unlit` 表示使用基本的**Unlit 材质**，适合在各种光照条件下使用
  - `Standard` 表示使用**标准 PBR 材质**，可以提供更好的海报细节和质感，适合需要更真实光照渲染的场景
  - `Uber` 表示使用**进阶 PBR 材质**，除了提供更好的细节和质感外，还支持 **LTCGI** 和 **AudioLink**，适合需要更高质量渲染和交互的场景
- `FeatureExt` (特性扩展) 部分用于指定预制件是否具有额外的特性
  - `Offline` 表示预制件支持展示**离线**海报内容，即不依赖在线**海报资源**，而是使用预先存储在本地的**海报资源**

## 进阶用法

海报展示组件通常由一个控制器组件以及一个或多个海报展示栏位构成。每个展示栏位都是一个使用了海报展示材质的表面。

### 关键概念

- **海报内容**：指可用于展示的一幅海报图像，比例通常为 9:16。
- **海报资源**：指用于存储**海报内容**的资源。一个资源可以包含多张**海报内容**。
- **展示栏位**：指用于展示**海报内容**的显示区域。
- **API 端点**：指用于获取在线**海报资源**的网络接口地址，系统会通过该地址请求并获取**海报资源**数据。
- **控制器**：指用于管理和控制**海报资源**展示的组件，对应 `PosterDisplayController` 组件。该组件负责通过 **API 端点**获取在线**海报资源**，并控制**海报栏位**的展示。单个控制器可以管理*一个*或*多个***展示栏位**的展示内容。
- **海报材质**：指用于渲染**海报内容**的材质。系统提供了多种不同类型的**海报材质**，以适应不同的展示需求。

## 控制器

控制器组件是海报展示系统中的核心组件，负责管理和控制一组**海报资源**在一个或多个**展示栏位**中的展示。

### 常用参数说明

在每个海报展示预制件中，都包含一个 `PosterDisplayController`（Controller）组件，用于管理一组在线海报内容的展示。该组件提供以下参数来控制展示效果：

| 属性名称 | 中文名称 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `Endpoint` | API 端点 | 用于指定在线**海报资源**的 API 端点地址，组件会通过该地址获取**海报资源**数据。 | — |
| `Duration Static` | 静态持续时间 | 用于指定**海报内容**展示的静态持续时间，单位为秒。 | 20 |
| `Duration Ease` | 过渡持续时间 | 用于指定**海报内容**切换的过渡持续时间，单位为秒。 | 0.5 |
| `Stride` | 步长 | 用于指定**海报资源**展示所使用的步长，在多栏位展示中控制每个**海报栏位**展示的内容。该参数通常需要配合 `Time Offsets` 使用。 | 1 |
| `Grid Horizontal` | 水平格数 | 用于指定**海报资源**排布的水平格数。 | 4 |
| `Grid Vertical` | 垂直格数 | 用于指定**海报资源**排布的垂直格数。 | 2 |
| `Start Download On Enable` | 启用时开始下载 | 用于指定是否在组件启用时自动开始从 **API 端点**下载**海报资源**。 | true |
| `Download Delay On Enable` | 启用后下载延迟 | 用于指定组件启用后开始下载**海报资源**的延迟时间，单位为秒。该参数可用于控制组件启用后开始下载的时机，避免在场景加载时过早发起网络请求而导致网络拥堵。 | 0.5 |
| `Target Renders` | 目标渲染器列表 | 用于指定**海报内容**的**展示栏位**渲染器列表，组件会将获取到的**海报内容**应用到这些渲染器上进行展示。 | 空列表 |
| `Time Offsets` | 时间偏移量列表 | 用于指定每个**展示栏位**的时间偏移量，单位为单个海报内容展示周期。如果 `Target Renders` 的数量大于 `Time Offsets` 的数量，后续**展示栏位**将以 round-robin 的方式重复使用 `Time Offsets` 中的值。 | 空列表 |

### Stride 和 Time Offsets 的配合使用 ———— 多栏位错开展示示例

在多栏位展示的预制件中，`Stride` 和 `Time Offsets` 参数通常需要配合使用，以确保每个**海报栏位**展示的内容能够正确错开。以下是一个示例：

假设有一个**海报资源**包含 8 张**海报内容**，并且有两个**展示栏位**需要展示这些内容。将 `Stride` 设置为 2，意味着每个**展示栏位**会每隔两张展示一张**海报内容**。然而，如果不调整 `Time Offsets`，两个**展示栏位**会同时展示相同的内容，即第 1、3、5、7 张**海报内容**。

为了让两个**展示栏位**展示不同的内容，需要调整 `Time Offsets`，使其中一个**展示栏位**相对于另一个错开一个海报内容展示周期。例如，可以将第一个**展示栏位**的 `Time Offsets` 设置为 0，将第二个**展示栏位**的 `Time Offsets` 设置为 1。这样，第一个**展示栏位**会展示第 1、3、5、7 张**海报内容**，第二个**展示栏位**会展示第 2、4、6、8 张**海报内容**，从而实现两个**展示栏位**展示不同内容的效果。

同理，如果有 4 个**展示栏位**，可以将 `Stride` 设置为 4，并将每个**展示栏位**的 `Time Offsets` 分别设置为 0、1.01、2.02、3.03。这样，第一个**展示栏位**会展示第 1、5 张**海报内容**，第二个**展示栏位**会展示第 2、6 张**海报内容**，第三个**展示栏位**会展示第 3、7 张**海报内容**，第四个**展示栏位**会展示第 4、8 张**海报内容**。同时，由于加入了小数部分的时间偏移，这几个栏位的切换时间也会被错开，从而避免所有栏位同时切换内容，提供更丰富的视觉效果。

## 海报展示材质

海报展示材质用于渲染**海报内容**。本组件提供以下几种不同的着色器，以支持不同类型的材质。

- `Xuan25/PosterDisplay`：基本的海报展示材质，使用 **Unlit 着色器**渲染**海报内容**，适合在各种光照条件下使用。
- `Xuan25/PosterDisplay/ORL-<Compiled/Configurable>/Standard`*：该材质使用**标准 PBR 着色器**，可以提供更好的海报细节和质感，如平滑度、金属度、法线纹理等。适合需要更真实光照渲染的场景。
- `Xuan25/PosterDisplay/ORL-<Compiled/Configurable>/Uber`*：该材质使用**进阶 PBR 着色器**。除了提供更好的细节和质感外，还支持 **LTCGI** 和 **AudioLink**，可提供更丰富的视觉效果和交互效果。适合需要更高质量渲染和交互的场景。

*：`Compiled` 和 `Configurable` 分别指编译版和可配置版着色器。其中，可配置版着色器依赖 [ORL 着色器](https://shaders.orels.sh/) 包。

除此之外，本组件还提供一个 ORL 着色器模块（`Shader/ORL/ORL-Module-PosterDisplay`），允许通过 [ORL 可配置着色器](https://shaders.orels.sh/docs/configurable-shaders) 自定义着色器，以满足更定制化的渲染需求。

### 常用参数说明

| 属性名称 | 中文名称 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `Texture/Poster Texture`* | 海报纹理 | 用于指定**海报资源**的纹理。 | 空纹理 |
| `Tint/Poster Tint` | 海报颜色调节 | 用于指定**海报内容**的颜色调节，可以改变**海报内容**的整体色调和亮度，以适应不同的展示需求。 | 白色 |
| `Static Duration`* | 静态持续时间 | 用于指定**海报内容**展示的静态持续时间，单位为秒。 | 1 |
| `Ease Duration`* | 过渡持续时间 | 用于指定**海报内容**展示的过渡持续时间，单位为秒。 | 0.5 |
| `Grid Horizontal`* | 水平格数 | 用于指定**海报资源**排布的水平格数。 | 4 |
| `Grid Vertical`* | 垂直格数 | 用于指定**海报资源**排布的垂直格数。 | 2 |
| `Stride`* | 步长 | 用于指定**海报资源**展示所使用的步长，在多栏位展示中控制每个**海报栏位**展示的内容。该参数通常需要配合 `Time Offsets` 使用。 | 1 |
| `Cell Margin` | 单元间距 | 用于指定**海报资源**中每个**海报内容**之间的间距，单位为 UV 坐标系中的比例值。 | 0.01 |
| `Ease Function` | 过渡效果函数 | 用于指定**海报内容**展示的过渡效果函数，可以改变**海报内容**切换时的动画效果。参考 [Easing Functions](https://easings.net/)。 | `EaseInOutCirc` |
| `Time Offset`* | 时间偏移量 | 用于指定**展示栏位**的时间偏移量，单位为单个海报内容展示周期。 | 0 |
| `Ease Animation` | 过渡动画 | 用于指定**海报内容**展示的过渡动画。 | `ZoomOut` |
| `Idle Texture` | 空闲纹理 | 用于指定**展示栏位**处于空闲状态时的纹理。 | 空纹理 |
| `Idle Tint` | 空闲颜色调节 | 用于指定**展示栏位**处于空闲状态时的颜色调节，可以改变空闲状态下的整体色调和亮度。 | 白色 |
| `Idling`* | 空闲状态 | 用于指定**展示栏位**是否处于空闲状态。 | 0 |
| `Idle Ease Mode` | 空闲过渡模式 | 用于指定**展示栏位**在空闲状态和展示状态之间切换时的过渡模式。 | `Lerp` |
| `Idle Ease Mask Texture` | 空闲过渡蒙版纹理 | 当 `Idle Ease Mode` 设置为 `Mask` 时，用于指定过渡蒙版的纹理。 | 空纹理 |
| `Idle Ease Mask Feather` | 空闲过渡蒙版羽化程度 | 当 `Idle Ease Mode` 设置为 `Mask` 时，用于指定过渡蒙版的羽化程度，单位为 UV 坐标系中的比例值。 | 0.1 |

*：若使用 `PosterDisplayController` 组件控制**海报内容**的展示，这些参数将由 `PosterDisplayController` 组件覆盖和控制，无法直接通过材质参数进行调整。
